# 鼠鼠小窝 · Mouse Nook

一个有温度的小鼠照护、繁育与家系记录应用。以 v2.0 PRD 为基线，使用 React、TypeScript、Node 和 SQLite；32 个原创毛绒鼠鼠姿态素材与轻量动效组成真实档案绑定的小窝场景。

## 本地运行

需要 Node ≥22.13，推荐 Node 24 LTS。

```sh
npm ci
npm run seed  # 可选：仅向空数据库导入 6 笼、15 只在笼小鼠的示例
npm run dev
```

打开 <http://127.0.0.1:5173>。默认数据库位于 `data/mouse-nook.sqlite`，刷新与重启后保留。跳过 seed 即从空小窝开始。`DATA_DIR` 可为不同环境指定独立数据库，示例导入不会覆盖现有资料。

```sh
npm test
npm run build
npm start  # 构建后的前后端统一由 3001 端口提供
```

`.env.example` 列出生产配置。`npm start` 自动加载 `.env`，生产实例必须配置 `APP_PASSWORD` 或已有受控访问入口。账号为 `admin`；默认仅绑定回环地址。

- 按实际换笼日顺延、批量完成、逐笼实际日期、历史补录与更正、改期、暂停、周期模板及下次生效。
- 月历 / 日程、当日清单、跨月逾期、实际 / 计划 / 预测区分。
- 配种、候选父本、观察、人工妊娠确认、计时依据、人工预计窗口、结束与历史时间轴。
- 窝次、零活体历史登记、活体幼鼠稳定建档、分批断奶与不同去向、独立哺乳和寄养关系。
- 局部家谱、家庭小剧场、同窝与子代、跨笼 / 归档亲本、循环约束、近亲提示。
- SQLite 原子提交、操作 ID 去重、版本冲突保留输入、事件历史、备份恢复。
- 独立服务端调度、Web Push 订阅 / 撤销 / 测试、持久化汇总队列、静默时段、退避、失效订阅、源版本校验与调度租约。

## 通知验收边界

滴答官方 MCP 未授权时返回 401，因此本版按 PRD 的备选路径交付 PWA Web Push。没有声称滴答已同步，也没有把服务接受通知写成手机已显示。

iPhone 需通过 HTTPS 将应用添加到主屏幕，再在设置里主动开启通知并发送测试。后台调度不依赖浏览器、聊天或桌面端常开。手机实际显示、关闭页面后的提前 / 到期通知仍须在真实手机上验收；状态见 [验收记录](docs/ACCEPTANCE.md)。
