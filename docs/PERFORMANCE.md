# 浏览器性能验收 · 2026-10-24

参考环境：Apple M1 Pro、32 GB 内存、macOS 27.0.1、Chrome；前端使用独立生产构建，Node 22.22.2 / SQLite API 与浏览器通过本机回环网络连接，没有网络限速。使用独立合成数据，不读取生产库。

| 数据规模 | 视口 / DPR | 首次可操作 | 6 次搜索 / 视图切换 | 8 秒 rAF 节奏 | 帧间隔 P95 | 最多活跃场景 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 20 笼 / 100 鼠 | 1512 × 861 / 2 | 382 ms | 14.7–62.5 ms | 107.3 次/秒 | 16.7 ms | 3 |
| 200 笼 / 1,000 鼠 | 1512 × 1400 / 1 | 419 ms | 15.6–97.8 ms | 101.5 次/秒 | 16.8 ms | 6 |

原始读数：[20 笼](assets/performance-20.json)、[200 笼](assets/performance-200.json)。两组视口不同，不能直接用帧节奏差异比较性能回归。采样均未进入页面后台；最差单帧间隔分别为 41.5 / 82.8 ms，不能宣称没有掉帧。

首次可操作时间从本次导航开始，包含 API 读取与首次 React 提交；交互记录为真实搜索 / 切换事件到第二个动画帧。动效读数是主线程 requestAnimationFrame 节奏，反映帧预算，不等同于 GPU 最终呈现帧率，也不代表 iPhone 或公网网络下的加载速度。

实际验证：

- 笼视图只渲染当前页 12 张卡；小鼠视图只渲染 30 行。搜索 `M0999`、`M1000` 可分别找到当前分页外的个体，未截断筛选源数据。
- 1,000 鼠时 6 张活跃场景最多包含 28 个实际角色；其他场景保持暂停。
- 用键盘聚焦 M0201，成员行高亮同一编号；后续观察中该鼠保持选中，其他笼动作继续切换。
- 全局暂停后 12 张卡全部为静态，活跃场景为 0；刷新后设置仍为 `static`，管理入口保留。
- 系统减少动效的监听和 CSS 降级已实现；本次没有修改用户的系统偏好，不把全局暂停测试冒充该系统设置的真机验证。

复现入口与命令见 [qa/README](../qa/README.md)。性能入口与采样代码不进入生产 `dist`；临时视口覆盖已恢复。
