# 实现与验收计划

产品基线为 `PRD-v2.0-鼠鼠小窝-优化版.md`；旧版中可靠性与通知语义继续适用。

## 交付阶段

1. 数据底座：React / TypeScript 前端、Node 服务、SQLite 持久化、事务、幂等操作、版本冲突、日期与关系约束。
2. 小窝体验：原创栅格鼠鼠精灵、稳定个体外观、动作调度、动态笼景、双视图、搜索筛选、档案抽屉。
3. 日常闭环：新增与编辑、照护、转笼、容量预览、周期换笼、月历与日程、提醒。
4. 繁育家庭：配种与观察、证据时间轴、窝次与外观候选、分批断奶、寄养、家谱与近亲提示。
5. 可靠运行：独立后台调度、持久化 Web Push 发件箱、订阅与测试、备份恢复、生产运行说明、自动与浏览器验收。

关键阶段通过检查后立即 Git 提交。数据库与凭据不进仓库，示例数据只由显式 seed 命令创建，空数据库可正常工作。

## 设计方向

温暖的绘本式小型实验室：奶油底、莓果粉、鼠尾草绿、纸张纹理；场景是有木屑、陶瓷窝、食盆和水瓶的小小立体剖面。鼠鼠采用原创毛绒质感精灵，多体色、多姿态、粉色圆耳、细长尾巴、小爪子与柔和阴影。每个形象对应唯一档案；表演与业务事实分开。

## 验收重点

- 69/70/139/140 日龄、闰日、时区与周龄提醒去重。
- 换笼按实际日顺延、旧补录不覆盖新记录、改期保留原应换日、空笼暂停、批量原子保存。
- 内部 ID 稳定、关系循环与性别/日期校验、观察不等于妊娠、候选父本不升级。
- 窝次只创建实际活体、分批断奶与转笼事务、哺乳独立结束。
- 刷新与服务重启持久化、重复操作与版本冲突、备份恢复。
- 桌面与手机尺寸、键盘抽屉、静态/减少动效、场景离屏暂停、搜索完整计数。
- 手机实际显示通知需 HTTPS 常驻服务及用户设备授权；未经设备实测不得标记真机验收通过。
