# 鼠鼠小窝 v2.0｜产品优化摘要

## 这次优化解决什么问题

初版已经能完成“看笼位、找小鼠、换笼、提醒、登记基础繁育”的可靠闭环，但鼠鼠仍主要是笼卡里的插画角色，谱系、妈妈/爸爸、孕期过程和个体差异还没有成为产品的核心体验。

v2.0 将产品主线改为：

> **日常照护 → 繁育记录 → 家庭追溯 → 可爱回顾**

首页仍然以鼠笼为中心，不增加复杂的后台式导航；用户可以从一笼鼠进入一只鼠，从一只鼠进入一窝和家谱，再回到今天要做的照护事项。

## 五个关键产品决定

### 1. 每只鼠有稳定的“身份”

- 编号是永远不变的主标识。
- 昵称是辅助身份，例如 `M003 · 奶糖`。
- 头像由体色、花纹、耳朵、眼睛、脸型、体型、尾巴和表情组合生成。
- 头像由稳定 `avatar_seed` 驱动，刷新、转笼、改昵称都不会改变。
- 同窝幼鼠共享柔和色系或小图案，同时在耳朵、斑块、表情上保留随机差异。

这样能实现“看起来像一家人，但每一只都认得出来”。

### 2. 外观可以有“遗传感”，但不冒充遗传结论

- 已知父母时，系统只生成 2–3 套亲本相似的外观候选。
- 用户确认后才锁定幼鼠头像。
- 未知亲本或没有遗传规则时，标记为“随机生成 / 待确认”。
- 每个 trait 都显示来源：妈妈相似、爸爸相似、同窝共享、随机生成、人工记录或未知。
- 真实表型单独记录，头像只是表现层。
- 可选遗传规则只做一致性提示，不自动填写基因型或父母。

### 3. 妊娠不再是一个下拉框，而是一条时间轴

建议使用以下节点：

```text
待配对 → 已配对 / 等待确认 → 受孕观察 → 妊娠已确认
      → 预计产仔窗口 → 实际产仔 → 哺乳中 → 分批断奶 → 休养 / 结束
```

每个节点保存日期、证据、来源和置信度。见栓只能显示“待确认”，没有计时基准时不显示精确孕日；预测产仔日期使用区间，不直接生成实际产仔事件。

### 4. 妈妈、爸爸、寄养母和同笼成员必须分开

建议至少支持：

- 生物学母亲
- 生物学父亲
- 候选父亲
- 寄养母
- 配偶 / 配种对象
- 同窝兄弟姐妹
- 同笼成员

当前笼位只表示空间位置，不能推断亲缘。转笼、归档和改编号不影响家谱。

### 5. 趣味性来自已记录的真实变化

增加以下轻量内容：

- 今日小窝摘要：换水、喂食、称重、观察、换笼和繁育节点
- 家庭小剧场：当前鼠、妈妈、爸爸、同窝、窝次和后代
- 小窝动态：根据已记录事件生成一句中性文案
- 成长纪念节点：出生、第一次睁眼、第一次独立进食、断奶、分笼
- 可关闭的性格标签：安静、好奇、爱睡、爱筑巢、贪吃、社交

不加入饥饿值、健康值、快乐值或必须照顾虚拟鼠才能完成工作的游戏机制。

## P0 交付顺序

1. 保留现有换笼、日历、提醒和数据一致性规则。
2. 先完成稳定个体头像和小鼠详情，再完成同窝候选头像。
3. 完成孕期时间轴、窝次实体、分批断奶和寄养关系。
4. 完成家庭小剧场与近亲提示。
5. 完成今日照护摘要和照护日历。
6. 最后接入小剧场文案和更多动作，避免先做动画再补数据模型。

## 推荐的下一轮原型页面

| 页面 | 必须回答的问题 |
| --- | --- |
| 首页 | 今天哪些笼、哪几只鼠需要关注？笼内鼠鼠是谁？ |
| 小鼠详情 | 这只鼠是谁？长什么样？在哪里？最近发生了什么？ |
| 繁育时间轴 | 当前处于哪个孕期节点？哪些是事实，哪些是预测？ |
| 窝次详情 | 这一窝有多少只？谁是妈妈/爸爸/寄养母？断奶到哪一步？ |
| 家庭小剧场 | 这只鼠来自哪个家庭？同窝和后代在哪里？ |
| 今日照护 | 今天完成了什么？还有什么待完成？ |

## 需要特别守住的边界

- 动画不能生成业务事实。
- 同笼不能自动生成亲子关系。
- 见栓不能自动变成妊娠确认。
- 预测产仔不能自动变成实际产仔。
- 头像颜色不能代替基因型、性别或健康状态。
- 父母更新不能静默重绘历史子代。
- 照护摘要只能来自真实记录。
